# Dr. Manoj Kumar Karnena – personal website

Source for **[manojkumarkarnena-prog.github.io](https://manojkumarkarnena-prog.github.io/)**, the academic homepage of Dr. Manoj Kumar Karnena, Assistant Professor of Water Treatment Technology at Yesbud University, Lusaka, Zambia, and an environmental scientist researching natural coagulants and sustainable water and wastewater treatment.

The site is a single static page (index.html) served by GitHub Pages. It covers experience, education, honours and awards, patents, books, selected publications and researcher profiles.
